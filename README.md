# 👗 Wardrobe Planner

Wardrobe Planner is a responsive and user-friendly web application designed to help users organize and plan their outfits efficiently. Whether you're preparing for a trip, planning weekly office looks, or simply trying to get the most out of your wardrobe, this tool has you covered.

---

## 🚀 Features

- ✨ User-friendly dashboard to view and manage outfits
- 👕 Add, edit, and remove clothing items
- 📷 Upload images of your clothes for a visual closet
- 🔍 Filter by color, type, season, or usage
- 📱 Fully responsive for mobile and desktop users

---

## 🛠️ Technologies Used

- HTML5 / CSS3 / JavaScript
- PHP & MySQL (for user authentication and storage)
- Responsive Design Principles
- Font Awesome / Google Fonts
- XAMPP / Apache (Local Development)
